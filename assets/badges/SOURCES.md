# Badge logo sources

AWS, Windows and VS Code marks are from Devicon, pinned at commit 6a37858047b0e8d9c9c0e68f4a071fc410652e89. AWS DMS uses the AWS vendor mark. The dbt mark is from Simple Icons 15.0.0 (CC0). The marks are embedded in local SVG badges so they do not depend on currently available Shields stock slugs.

- [Devicon AWS mark](https://github.com/devicons/devicon/blob/6a37858047b0e8d9c9c0e68f4a071fc410652e89/icons/amazonwebservices/amazonwebservices-original-wordmark.svg)
- [Devicon Windows mark](https://github.com/devicons/devicon/blob/6a37858047b0e8d9c9c0e68f4a071fc410652e89/icons/windows11/windows11-original.svg)
- [Devicon VS Code mark](https://github.com/devicons/devicon/blob/6a37858047b0e8d9c9c0e68f4a071fc410652e89/icons/vscode/vscode-original.svg)
- [Simple Icons dbt mark](https://github.com/simple-icons/simple-icons/blob/15.0.0/icons/dbt.svg)
